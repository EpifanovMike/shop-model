# 📊 Финансовая модель розничной сети (РФ): Розница, Опт и Офис

Интерактивный веб-калькулятор юнит-экономики и финансового планирования для розничного бизнеса и торговых сетей в России. Позволяет за несколько минут рассчитать стартовые инвестиции (CAPEX + товарный запас), построить отчет о прибылях и убытках (P&L), оценить реальную окупаемость с учетом периода разгона и определить точку безубыточности всей сети с учетом оптового канала и расходов управляющего офиса.

---

## ✨ Ключевые возможности

### 1. Юнит-экономика и товарный запас (CAPEX + ТЗ)
* **Расчет товарного остатка:** автоматический расчет объема закупки в единицах для торгового зала (по площади и плотности выкладки) и подсобного склада в выбранной валюте закупки (**USD**, **EUR** или **CNY**).
* **Эффективная наценка:** учет влияния сезонных распродаж, акций и бонусов на базовую торговую наценку.
* **Детализированный CAPEX:** постатейный учет затрат на открытие (СМР, освещение, вывеска, торговое оборудование, антикражная система, раскрываемый ИТ-блок) за вычетом компенсаций от ТЦ или бренда.

### 2. Налоговая модель Российской Федерации
* **Готовые пресеты налоговых режимов РФ:**
  * `ИП / ООО УСН Доходы (6%)`
  * `УСН Доходы (6% + НДС 5%)`
  * `УСН Доходы (6% + НДС 7%)`
  * `УСН Доходы − Расходы (15%)`
  * `ООО ОСНО (Налог на прибыль 25% + НДС 20%)`
  * `Настраиваемый режим` (ручной ввод любых ставок)
* **Корректный учет НДС:** автоматическое выделение исходящего НДС из выручки с чеков; для ОСНО (20%) применяется вычет входного НДС с закупки товара, для льготного УСН НДС (5% / 7%) налог рассчитывается с оборота.
* **Прозрачный расчет ФОТ и зарплатных налогов:**
  * Переключатель типа оклада: **«На руки (Net)»** (с автоматическим начислением НДФЛ сверху) или **«По договору (Gross)»**.
  * Переменная мотивация продавцов (**% бонуса от выручки**).
  * Раздельный расчет **НДФЛ (13%)** и **страховых взносов СФР: ПФР, ФСС, ОМС (30,2%)**.
### 3. Оптовый блок и управляющий офис
* Расчет чистой прибыли оптового канала с защитой от отрицательной наценки.
* Расчет **точки безубыточности всей сети**: точное количество розничных магазинов, необходимое для полного покрытия расходов управляющего офиса (с учетом вклада оптового направления).
* Итоговая чистая прибыль всей сети при целевом количестве магазинов.

### 4. Официальные курсы ЦБ РФ и мультивалютная закупка
* Поддержка трех валют закупки товара: **Доллар США (`USD`)**, **Евро (`EUR`)** и **Китайский юань (`CNY`)**.
* Автоматическая загрузка актуальных официальных курсов Центробанка РФ из открытого JSON-фида (`cbr-xml-daily.ru`) с возможностью ручной корректировки курса под банковский спред.

### 5. Аналитика, A/B-сценарии и визуализация
* **Сравнение «План А» vs «План Б»:** мгновенное клонирование базового сценария, стресс-тестирование параметров и сводная таблица разницы показателей.
* **Период разгона (Ramp-up):** моделирование плавного выхода нового магазина на плановую выручку (`0`, `2`, `3` или `6` месяцев) с расчетом реального срока окупаемости.
* **График окупаемости (24 месяца):** адаптивный SVG-график накопленного денежного потока (Cumulative Cash Flow) для наглядного сравнения сроков возврата инвестиций по двум сценариям.
* **Помесячный Cash Flow (12 месяцев):** детальная таблица движения денежных средств по месяцам с учетом загрузки, НДС, себестоимости, OPEX и налогов.
* **Экспорт и сохранение:** автосохранение введенных данных в `localStorage`, выгрузка отчета в **Excel (`.csv`)** и чистая верстка для **печати / сохранения в PDF**.

Проект написан на чистом **HTML5, CSS3 и Vanilla JavaScript** без сторонних фреймворков и сборщиков — работает мгновенно при открытии в любом современном браузере:

```text
├── index.html   # Основной интерфейс калькулятора (KPI, формы ввода, P&L, таблицы и график)

└── README.md    # Документация проекта
```

## 🚀 Быстрый запуск и развертывание

### Локальный запуск
1. Склонируйте репозиторий или скачайте архив с файлами:
   ```bash
   git clone https://github.com
   ```
2. Откройте файл `index.html` двойным кликом в любом современном браузере (Chrome, Safari, Firefox, Edge, Яндекс Браузер).
3. При наличии подключения к интернету калькулятор автоматически загрузит актуальные курсы `USD`, `EUR` и `CNY` по данным ЦБ РФ. При работе офлайн используются базовые значения, которые можно изменить вручную.

### Публикация на GitHub Pages
1. Загрузите файлы репозитория на GitHub.
2. Перейдите в **Settings → Pages** вашего репозитория.
3. В разделе **Build and deployment → Source** выберите `Deploy from a branch`, укажите ветку `main` и корневую папку `/ (root)`, затем нажмите **Save**.
4. Через 1–2 минуты калькулятор будет доступен по публичной ссылке вида `https://github.io`.

## 🧮 Основные формулы финансовой модели

| Показатель | Формула расчета |
| :--- | :--- |
| **Товарный запас (ТЗ)** | `(Площадь зала × Плотность × (1 + % склада)) × Цена закупа × Курс ЦБ РФ` |
| **Эффективная наценка** | `(1 + Стартовая наценка) × (1 − Средняя скидка) − 1` |
| **Выручка без НДС** | `Выручка с чеков / (1 + Ставка НДС)` |
| **Себестоимость (COGS)** | `Выручка без НДС / (1 + Эффективная наценка)` |
| **Начисленный ФОТ (Gross)** | При расчете «На руки»: `(Оклады + Бонус от выручки) / (1 − % НДФЛ)` |
| **Страховые взносы СФР** | `ФОТ Gross × Ставка СФР (ПФР + ФСС + ОМС + травматизм)` |
| **EBITDA** | `Валовая прибыль − OPEX (включая ФОТ и взносы)` |
| **Чистая прибыль (Net Profit)** | `EBITDA − Амортизация − Налог бизнеса (УСН / ОСНО)` |
| **Точка безубыточности (BEP)** | `(Постоянный OPEX + Амортизация) / Коэффициент маржинального дохода` |
| **Реальная окупаемость** | Месяц, в котором `Накопленный денежный поток (CF) ≥ (CAPEX + ТЗ)` |
| **Безубыточность сети** | `Округление вверх ((Расходы офиса − Чистая прибыль опта) / Чистая прибыль 1 магазина)` |
